One letter for a whole day: **I — for insomnia**. Awake when the rest of
the world is asleep. The letter is the whole entry: no word, no gloss,
no punctuation.

## Run it

```sh
python3 main.py
```

`main.py` writes exactly one character, `I`, to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). No network, no
randomness, no clock: two runs write the same byte.
